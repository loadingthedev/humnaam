# humnaam

Decides whether two person names are the same person's name. Built for South Asian and Arabic names written in Latin letters: "Mohammed / Muhammad / Mohd", "Chaudhary / Choudhury", initials, swapped word order.

"Humnaam" means namesake in Hindi and Urdu. It is also spelled "hamnaam".

Not usable yet. The plan and the order of work are in Linear issue LIF-236.
